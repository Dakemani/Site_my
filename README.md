# Лабораторная работа: Набор скриптов для командной строки

## 📋 Описание задания

Создание набора из 7 скриптов на языке shell (`/bin/sh`) для выполнения различных задач в командной строке. Все скрипты должны быть совместимы с Bourne shell и использовать только стандартные Unix-утилиты.

## 📁 Список скриптов

### 1. `greeting.sh` - Приветствие пользователя
**Задача:** Запросить имя пользователя и вывести персонализированное приветствие.

**Особенности:**
- Проверка ввода пустого имени
- Простое и понятное взаимодействие

### 2. `calculator.sh` - Калькулятор суммы
**Задача:** Запросить два числа и вывести их сумму.

**Особенности:**
- Поддержка целых и дробных чисел
- Валидация ввода
- Использование `awk` для точных вычислений

### 3. `even_odd.sh` - Проверка четности числа
**Задача:** Определить, является ли введенное число четным или нечетным.

**Особенности:**
- Работа с отрицательными числами
- Проверка на целое число
- Алгоритм без оператора деления по модулю

### 4. `create_project.sh` - Создатель структуры проектов
**Задача:** Создать структуру папок для веб-проекта.

**Создаваемая структура:**
```
my-project/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

**Особенности:**
- Автоматическое создание файлов с базовым содержимым
- Проверка существования проекта

### 5. `line_counter.sh` - Счетчик строк в файле
**Задача:** Подсчитать количество строк в указанном файле.

**Особенности:**
- Проверка существования файла
- Использование `wc -l`
- Простой и понятный вывод

### 6. `password_generator.sh` - Генератор паролей
**Задача:** Сгенерировать случайный пароль длиной 8 символов.

**Особенности:**
- Использование `/dev/urandom` для криптографической безопасности
- Разнообразный набор символов
- Совместимый алгоритм для разных систем

### 7. `file_search.sh` - Поиск файлов
**Задача:** Найти файлы по расширению в текущей директории.

**Особенности:**
- Подсчет найденных файлов
- Четкий вывод результатов
- Обработка случая, когда файлы не найдены
